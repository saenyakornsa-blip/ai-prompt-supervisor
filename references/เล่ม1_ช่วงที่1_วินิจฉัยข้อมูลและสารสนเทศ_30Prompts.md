### Prompt 1.2 : Supervisor Persona Builder — กำหนดบทบาทโค้ช/ผู้นำวิชาการตามสถานการณ์

```text
กำหนดบทบาท (Persona) ของคุณในการให้คำปรึกษางานนิเทศการศึกษาสำหรับสถานการณ์นี้:
สถานการณ์นิเทศ: [เช่น เตรียมลงพื้นที่ตรวจเยี่ยมโรงเรียนขนาดเล็กที่ครูมีความวิตกกังวลสูงเรื่องการประเมิน วPA]

1. 'ผู้นำทางวิชาการ (Instructional Leader)': ให้ข้อเสนอแนะเชิงทฤษฎีและมาตรฐานหลักสูตรที่ถูกต้อง ชัดเจน
```

### Prompt 1.3 : Chain-of-Thought (CoT) for Supervisors — วางลำดับคิดเชิงยุทธศาสตร์การนิเทศ
> **หมวดงาน:** เสาที่ 1 | **บทที่:** 1 | **สถานการณ์:** วางแผน
> **แท็ก:** CoT, คิดเป็นขั้น, ยุทธศาสตร์, แก้ปัญหาเชิงระบบ

```text
ก่อนที่คุณจะให้คำตอบหรือร่างข้อเสนอแนะ ให้แสดง 'กระบวนการคิดทีละขั้น (Chain-of-Thought)' อย่างเป็นระบบตามลำดับนี้:
โจทย์/ปัญหาการนิเทศ: [เช่น ผลคะแนน O-NET ภาษาไทย ป.6 ตกต่ำต่อเนื่อง 3 ปีในกลุ่มโรงเรียนขยายโอกาส 5 แห่ง]
ขั้นตอนการคิดวิเคราะห์:
ขั้นที่ 1: การจำแนกประเภทของปัญหา (ปัญหาด้านครู, ด้านนักเรียน, ด้านทรัพยากร, หรือด้านระบบบริหาร)
ขั้นที่ 2: การสกัดช่องว่างความต้องการจำเป็น (Need Gap Analysis) เทียบกับมาตรฐานชาติ
ขั้นที่ 3: การประเมินข้อจำกัดเชิงบริบท (Contextual Constraints) เช่น ข้อจำกัดด้านเวลาและงบประมาณ
ขั้นที่ 4: การออกแบบชุดมาตรการนิเทศเชิงรุก (Intervention Strategy)
ขั้นที่ 5: การสรุปเป็นข้อเสนอแนะเชิงปฏิบัติการที่จับต้องได้
เมื่อแสดงการคิดวิเคราะห์ครบทั้ง 5 ขั้นแล้ว จึงสรุปเป็นร่างแนวทางปฏิบัติการนิเทศฉบับสมบูรณ์
```

* **💡 วิธีใช้:** เทคนิค CoT ช่วยให้ AI ไม่ด่วนสรุปคำตอบแบบผิวเผิน แต่จะช่วยกลั่นกรองปัญหาเชิงระบบได้อย่างลึกซึ้ง
* **🔧 จุดปรับแต่ง:** `[โจทย์/ปัญหาการนิเทศ]`

### Prompt 1.4 : Policy Deconstructer — ถอดรหัสนโยบายกระทรวงสู่ภารกิจเขตพื้นที่

> **แท็ก:** ถอดรหัสนโยบาย, Policy Translation, KPI, ขับเคลื่อนเขต

```text
ช่วยถอดรหัสนโยบายทางการศึกษาฉบับนี้ แปลงเป็นแนวปฏิบัติและแผนนิเทศระดับเขตพื้นที่:
ข้อความ/เอกสารนโยบาย: [วางข้อความนโยบาย เช่น นโยบาย 'เรียนดี มีความสุข' / แผนยกระดับ PISA แห่งชาติ / 1 อำเภอ 1 โรงเรียนคุณภาพ]
บริบทเขตพื้นที่ของผม: [ระบุ เช่น สพป. เขตพื้นที่ชนบท มีโรงเรียนขนาดเล็ก 40%]
วิเคราะห์และสังเคราะห์เป็น 4 มิติ:
1. สาระสำคัญและเจตนารมณ์แท้จริงของนโยบาย (The Core Intent)
2. การแปลงเป้าหมายใหญ่ (Strategic Goals) สู่ตัวชี้วัดความสำเร็จระดับโรงเรียน (Actionable KPIs)
3. บทบาทเฉพาะของศึกษานิเทศก์ในการขับเคลื่อน (จุดที่ ศน. ต้องลงไปสนับสนุนครูโดยตรง)
4. อุปสรรคที่อาจพบในระดับปฏิบัติการ (Potential Bottlenecks) และแนวทางป้องกันล่วงหน้า
```

* **🔧 จุดปรับแต่ง:** `[ข้อความ/เอกสารนโยบาย] [บริบทเขตพื้นที่ของผม]`

### Prompt 1.5 : Educational Data Prompt — รูปแบบการป้อนสถิติและข้อมูลคะแนนเข้าสู่ AI

```text
คุณคือผู้เชี่ยวชาญการวิเคราะห์สถิติทางการศึกษา (Educational Data Analyst)
ผมกำลังจะป้อนข้อมูลผลคะแนนทางการศึกษาของสถานศึกษาในเขตพื้นที่
รูปแบบข้อมูลที่ผมจะป้อน:
- การทดสอบ: [เช่น NT ป.3 / O-NET ป.6 / ผลสำรวจ PISA-like]
- กลุ่มเป้าหมาย: [เช่น โรงเรียนขยายโอกาส 8 แห่ง ในเครือข่ายที่ 2]

[วางตารางคะแนนเฉลี่ย, ร้อยละ, หรือค่าส่วนเบี่ยงเบนมาตรฐาน (SD) ที่คัดลอกมาจาก Excel หรือ PDF รายงานผล]
```


### Prompt 2.14 : Classical Item Analysis — วิเคราะห์ค่าความยาก (p) และอำนาจจำแนก (r) ของแบบทดสอบ
> **หมวดงาน:** เสาที่ 1 | **บทที่:** 2 | **สถานการณ์:** วางแผน, เครื่องมือ
> **แท็ก:** Item Analysis, ค่าความยาก p, อำนาจจำแนก r, คัดเลือกข้อสอบ

```text
คุณคือผู้เชี่ยวชาญด้านการวัดและประเมินผลทางการศึกษา (Psychometrician)
ช่วยวิเคราะห์คุณภาพข้อสอบอิงกลุ่มตามทฤษฎีการทดสอบแบบดั้งเดิม (Classical Test Theory - CTT):
ข้อมูลผลการตอบข้อสอบ:
[ระบุข้อมูลสถิติรายข้อ เช่น จำนวนคนตอบถูกในกลุ่มสูง (H), กลุ่มต่ำ (L), และจำนวนคนทั้งหมด (N) หรือระบุค่า p และ r ที่คำนวณมาแล้ว]
ดำเนินการวิเคราะห์คุณภาพเครื่องมือ:
1. การแปลผลค่าความยากง่าย (p): ระบุข้อที่ 'ยากเกินไป (p < 0.20)', 'ง่ายเกินไป (p > 0.80)', และ 'พอเหมาะ (0.20 - 0.80)'
2. การแปลผลค่าอำนาจจำแนก (r): ระบุข้อที่มีอำนาจจำแนกดี (r >= 0.20) และข้อที่มีปัญหา (r < 0.20 หรือติดลบ)
3. การวินิจฉัยข้อสอบที่ติดลบ: วิเคราะห์ว่าทำไมเด็กเก่งถึงตอบผิดแต่เด็กอ่อนตอบถูก (โจทย์กำกวม, เฉลยผิด, หรือตัวลวงดึงดูดเด็กเก่ง)
4. สรุปข้อสอบที่ 'ควรเก็บไว้', 'ควรปรับปรุง', และ 'ควรตัดทิ้ง' สำหรับการสร้างคลังข้อสอบมาตรฐาน
```

* **💡 วิธีใช้:** ใช้ในภารกิจกลุ่มงานวัดและประเมินผลการศึกษา เพื่อคัดเลือกข้อสอบที่มีคุณภาพสูงเข้าสู่คลังข้อสอบเขต
* **🔧 จุดปรับแต่ง:** `[ข้อมูลผลการตอบข้อสอบ]`

### Prompt 2.17 : HOTS Question Generator for Supervisors — แนวทางสร้างข้อสอบวัดการคิดขั้นสูง

```text

สร้างข้อสอบจำนวน 2 ข้อ พร้อมองค์ประกอบสมบูรณ์:
1. สถานการณ์นำ (Contextual Stimulus) ที่มีความสมจริง ไม่ใช่คำถามความจำตรงๆ
2. คำถามที่บังคับให้ผู้เรียนต้องเชื่อมโยงหลักการ เปรียบเทียบ หรือตัดสินใจอย่างมีหลักฐาน
3. ตัวเลือก 4 ตัวที่มีเหตุผลรองรับ พร้อมระบุคำอธิบายว่าทำไมข้อถูกจึงถูก และตัวลวงแต่ละข้อสะท้อนความคิดผิดแบบใด
4. คำแนะนำสำหรับครูในการนำข้อสอบข้อนี้ไปใช้จัดกิจกรรมสนทนาในห้องเรียน (Debriefing Question)
```

* **💡 วิธีใช้:** ครูมักออกข้อสอบได้แค่วัดความจำ Prompt นี้จะช่วยให้ ศน. มีคลังตัวอย่างข้อสอบ HOTS ไปสาธิตให้ครูดูเป็นต้นแบบ
* **🔧 จุดปรับแต่ง:** `[มาตรฐาน/ตัวชี้วัด] [ระดับการคิดเป้าหมาย] [บริบทในชีวิตจริง]`

### Prompt 2.19 : Longitudinal Trend Analysis — วิเคราะห์แนวโน้มผลสัมฤทธิ์ทางการศึกษาย้อนหลัง 3-5 ปี

> **แท็ก:** Longitudinal Trend, แนวโน้ม 5 ปี, พยากรณ์ผล, ยุทธศาสตร์เขต

```text
คุณคือผู้เชี่ยวชาญด้านสถิติยุทธศาสตร์ทางการศึกษา
ช่วยวิเคราะห์แนวโน้มผลสัมฤทธิ์ทางการศึกษาแบบระยะยาว (Longitudinal Trend Analysis) ย้อนหลัง 3-5 ปี:
ข้อมูลสถิติย้อนหลัง:
- การทดสอบ: [เช่น O-NET ป.6 หรือ NT ป.3]
- ข้อมูลคะแนนเฉลี่ยย้อนหลัง:
[เช่น ปี 2564 = 48.2, ปี 2565 = 45.1, ปี 2566 = 49.3, ปี 2567 = 51.0]
- ปัจจัยแวดล้อมที่เกิดขึ้น: [เช่น ช่วงโควิด-19, การเปลี่ยนหลักสูตร, การจัดสรรงบประมาณพัฒนาครู]
ดำเนินการวิเคราะห์เชิงยุทธศาสตร์:
1. การระบุรูปแบบแนวโน้ม (Trend Pattern): ขาขึ้น (Upward), ขาลง (Downward), หรือคงที่แกว่งตัว (Stagnant)

```

* **💡 วิธีใช้:** ใช้จัดทำบทวิเคราะห์ในเล่มแผนยุทธศาสตร์เขตพื้นที่ ช่วยให้เห็นภาพรวมระยะยาวไม่ใช่แค่มองปีต่อปี
